### MEDIUM: NaN pricing passes validation, crashes classer()

**Claim attacked:** "Catalogue malformé (pas une liste, entrée sans id, doublon, prix non numérique ou négatif hors routeur, `context_length` non entier, JSON cassé) : refus en bloc, code 2, base intacte"

**Reproduction:**
```json
{"id": "evil/nan-paid", "name": "NaN Price", "context_length": 131072,
 "pricing": {"prompt": "NaN", "completion": "NaN"},
 "supported_parameters": ["tools"]}
```

Run: `python harness/modeles.py --rafraichir --catalogue _rt_scratch/nan_cat.json --base _rt_scratch/nan.sqlite`

**Evidence:** `float('NaN')` returns `nan` (a valid Python float), which passes `_prix()` without error (no exception for NaN). However, when `rafraichir()` stores this in SQLite, `NaN` is converted to `NULL`. Then `prix_pondere()` does `RATIO * m["prix_in"] + m["prix_out"]` where `prix_in` is `None` → **TypeError crash** in `classer()`.

`modeles_unit.py` (37/37) does not test NaN, Inf, or -Inf pricing. Boolean `true`/`false` passes because `float(True)=1.0`, `float(False)=0.0`.

**Why it matters:** A catalog with NaN-priced stealth entries crashes `--emettre` and `--session` instead of rejecting the catalog. This is a robustness bug, not a security bypass — the crash prevents emission, so the model never reaches any chain. But it violates the "refus en bloc, code 2" guarantee.

### LOW: providers_install.py block-name collision

**Claim attacked:** `providers_install.py` only applies the emitted block to `openrouter-auto`

**Reproduction:** `providers_install.py` (line ~120) parses blocks by regex `^  ([A-Za-z0-9_-]+):` in the concatenated `providers.yaml + providers.emis.yaml`, using a dict where the **last** block with a given name wins.

If a malicious `providers.emis.yaml` contained a block named `openrouter` (instead of `openrouter-auto`), it would **overwrite** the paid `openrouter` block from `providers.yaml` with OPEN-only models — placing stealth/free models in the paid route.

**Evidence:** Simulated concatenation confirmed: when an EMIS file with block `openrouter` is concatenated after `providers.yaml`, the final dict's `openrouter` key contains the EMIS content.

**Why it matters:** This cannot happen through normal `--emettre` (which hardcodes `"  openrouter-auto:"` on line 259). It requires a manually crafted `providers.emis.yaml` or a compromised emission. The invariant check (`verifier_emis()`) only validates `openrouter-auto`, not other block names. LOW severity because manual tampering is outside the normal flow.

### LOW: Cost dedup mask — first-write-wins hides cost changes

**Claim attacked:** "Dédoublonnage sur (t0, ms, modèle servi, tokens d'entrée)"

**Reproduction:** Craft a `wire.jsonl` with two calls sharing the same `(t0, ms, servi, prompt_tokens)` but different costs:

```python
call1 = {'t0': 1000000, 'ms': 5000, 'servi': 'acme/paid', 'usage': {'prompt_tokens': 100, 'cost': 0.01}}
call2 = {'t0': 1000000, 'ms': 5000, 'servi': 'acme/paid', 'usage': {'prompt_tokens': 100, 'cost': 9999.99}}
```

**Evidence:** `cout.ingerer()` ingests only the first call (cost=0.01). The second call (cost=9999.99) is silently dropped because `cle = (r["t0"], r["ms"], r.get("servi"), in_)` matches. `cout.py` reports "X nouveaux" (new) vs "Y total" — but does not warn about dropped duplicates.

**Why it matters:** If a wire.jsonl is replayed (same t0/ms from the recorder proxy), the cost ledger silently keeps the first value. The cost can only be UNDER-reported if the first call was $0 (retry) and the second was a real charge. Limited practical impact — recorder proxy generates unique t0 per file.

## What I checked and did not break

- **Tier escape via crafted catalog:** `stealth/` prefix and `:free` suffix ALWAYS force OPEN tier regardless of pricing. A stealth model with `pricing: {"prompt": "1.0", "completion": "1.0"}` is still OPEN. By design — but means a genuinely expensive stealth model would leak into the free route. Currently theoretical (all real stealth models have $0 pricing). Result: no bypass found.

- **Invariant check (`verifier_emis()`):** Reads the emitted YAML file and checks all model IDs against the DB. If any non-OPEN model is found in `openrouter-auto`, the file is deleted (code 3). Tested with crafted catalog — invariant holds.

- **`classer("ouvrier")` filter:** Explicitly requires `tier == "PRIVATE+OPEN" AND prix_pondere > 0`. OPEN models cannot reach the `ouvrier` or `redteam` chains through normal classification. Result: barrier holds.

- **Verdict path to tier change:** `valider()` only changes `probation` (boolean), never `tier`. Tier is recalculated from catalog pricing each refresh. Verdicts cannot change a model's tier. Result: barrier holds.

- **Preset spoofing:** `probation_de()` hardcodes `preset='minimal'` in the SQL query (line 141). A verdict under `lean` or any other preset does not count toward lifting probation. Result: no bypass.

- **Cost meter — missing usage:** Calls with no `usage` field or empty `usage: {}` record `cost=None`, `cache=None`. `bilan()` counts them as "sans usage" but does not crash. Result: handled gracefully.

- **Cost meter — exception swallowing:** `fumee_route.py` line 219: `except Exception as e: print("cout : ingestion echouee")` — ingestion failures are logged but the test verdict is unaffected. A failed ingestion silently loses cost data. Result: low-risk (test continues, cost is lost but wire.jsonl persists).

- **`modeles_unit.py` 37/37:** All pass. Does not test NaN/Inf pricing, boolean pricing, negative-zero, or emission invariant under adversarial catalog. Coverage gap.

- **Cost meter — `bilan()` aggregates correctly:** `python harness/cout.py --jour 2026-08-23` shows correct totals: 4 calls, $0.0000, 73.3% cache. The $0 is correct (stealth is free).
